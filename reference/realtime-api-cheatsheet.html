Everything you need on one page for the weather & air app. Prints on two sides of A4.

Auth

x-api-key: YOUR_API_KEY

Optional for testing, recommended for production. Server-side only, never in client bundles. docs · request a key

Query params

Timestamps are ISO-8601 with +08:00 (SGT).

Useful metrics in psi readings include psi_twenty_four_hourly, pm10_twenty_four_hourly and no2_one_hour_max. pm25 gives pm25_one_hourly in µg/m³. Full schemas are in the API catalogue.

The core pattern

1. check json.code === 0           (else data is null)
2. pick latest item by timestamp   (items is a time series; never blind items[0])
3. nearest place to user (haversine on label_location / location)
4. join place → value by name / id

Terms used in this course

EnvelopeThe {code, errorMsg, data} wrapper around every v2 response.
MetadataThe array of places (areas, regions, stations) with coordinates.
Item / readingOne timestamped snapshot of values for those places.
Shape familyOne of the four response layouts above. Write one adapter per family.
